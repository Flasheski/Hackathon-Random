# 🍍 Le Méga Casino de Bikini Bottom 🧽

# CONTRIBUTORS : [Flasheski](https://github.com/Flasheski) && [Fabien](https://github.com/Fabienskotarek)

Bienvenue au **Méga Casino de Bikini Bottom** ! Ce projet est un jeu de casino interactif développé en Python avec **Pygame**. Il a été créé à l'occasion d'une Game Jam autour d'un défi collaboratif spécial : un crossover avec le groupe "Casino Valorant".

Plongez sous l'océan, retrouvez l'univers de Bob l'éponge et affrontez Carlo le croupier dans différents mini-jeux de hasard et de réflexion !

---

## 🎮 Mini-Jeux Inclus

1. 🃏 **Blackjack** Affrontez le croupier Carlo Tentacule. Tirez des cartes pour vous rapprocher d'un score de 21 sans jamais le dépasser. Si vous battez le croupier 5 fois, vous remportez la victoire !
   
2. 🎲 **421 (Jeu de dés)** Le célèbre jeu de dés de comptoir. Vous disposez de 3 lancers par manche pour réaliser la meilleure combinaison possible (le 4-2-1 étant la meilleure). Sélectionnez les dés à conserver, relancez les autres, et tentez de battre la combinaison du croupier. Le premier à 5 victoires gagne.

3. 🧠 **QCM Spécial JAM** Un quiz exclusif pour tester vos connaissances pointues sur les habitants de Bikini Bottom et sur l'univers tactique du jeu Valorant (pour respecter le défi du crossover !).

---

## 🛠️ Prérequis et Installation

Pour pouvoir jouer, vous devez avoir **Python 3** installé sur votre machine, ainsi que la bibliothèque **Pygame**.

1. **Cloner le dépôt** (ou télécharger le code source en `.zip`) :
   Assurez-vous de bien conserver l'arborescence du projet (les dossiers `sprites/`, `sounds/` et `font/` doivent rester au même niveau que le script principal).

2. **Installer Pygame** :
   Ouvrez un terminal ou une invite de commande et tapez :
   ```bash
   pip install pygame
   ```

3. **Lancer le jeu avec la commande** :
   ```bash
   python3 sponge.py
   ```
